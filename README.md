# Scientifico

This is Scientifico and it is a simple science flashcard website with built in flashcards ranging from chemistry to biology. The questions are very simple too, so that is amazing and very user-friendly. I created this to help me study for science because this year I gotta lock in so this project helped at the same time too.

![sci.png](sci.png)


## Features

- Biology questions
- Chem questions
- Simple to use
- Flipabble 
- Colour scheme is green and pink with black text and good font style (comic cursive)

## Future things to add

I want to make the flashcards more on the user side, so that the user can input their own flashcards. There is also one other thing I wanted to add and that is a space recognition system, which will use statistical data that the user provides kind of like Ankis flashcards.
